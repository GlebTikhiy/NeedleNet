# Versioning

NeedleNet uses its own Semantic Versioning: `MAJOR.MINOR.PATCH`, with preview identifiers such as `0.1.0-preview.5`.

- Runtime version: `0.1.0-preview.5`.
- Git tag: `v0.1.0-preview.5`.
- Player archive: `NeedleNet-0.1.0-preview.5-Windows.zip`.
- Next revision of this preview: `0.1.0-preview.6`.
- Stable release of this version, once validated: `0.1.0`.

Game build compatibility and upstream mod versions are documented separately. The maintenance base for the first preview is `0.19.6-xRangerDE.79`, pinned at `a9e8ecf42ab4baf75f8c5394bb27447b5e4b3cd3`; supported game build is 25963876.

The initial preview.1 replaced the previous NeedleNet .5 label. Subsequent previews contain documented fixes. The network handshake compares version strings, so every participant should update together.
